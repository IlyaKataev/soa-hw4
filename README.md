Проектирование централизованной платформы уведомлений для онлайн-банка.

## Краткое содержание

Система: централизованная Notification Platform для банка с 10M MAU.  
Типы уведомлений: транзакционные (критичные), сервисные, маркетинговые.  
Каналы: push, SMS, email.

RFC рассматривает два варианта архитектуры подсистемы гарантированной доставки транзакционных уведомлений:

- **Вариант 1 — Centralized Orchestrator**: Redis Streams для транзакционного fast-path, Kafka для остальных, единый state machine в PostgreSQL. Рекомендован.
- **Вариант 2 — Event-Driven Choreography + Saga**: только Kafka, failover через события между независимыми Consumer-сервисами.
